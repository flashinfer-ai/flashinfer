flashinfer.cake_gdn_det_train_kcp
=================================

Cake deterministic GDN KCP training helpers and entry points. The module is a
stable API; its backend package,
``flashinfer.experimental.cake.cake_gdn_det_train_kcp``, is experimental and is
imported on first use.
