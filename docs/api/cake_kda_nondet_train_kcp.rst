flashinfer.cake_kda_nondet_train_kcp
====================================

Cake non-deterministic KDA KCP training helpers and entry points. The module is
a stable API; its backend package,
``flashinfer.experimental.cake.cake_kda_nondet_train_kcp``, is experimental and
is imported on first use.
