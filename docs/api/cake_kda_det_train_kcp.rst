flashinfer.cake_kda_det_train_kcp
=================================

Cake deterministic KDA KCP training helpers and entry points. The module is a
stable API; its backend package,
``flashinfer.experimental.cake.cake_kda_det_train_kcp``, is experimental and is
imported on first use.
