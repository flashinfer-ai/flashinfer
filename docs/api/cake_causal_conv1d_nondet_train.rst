flashinfer.cake_causal_conv1d_nondet_train
==========================================

Cake non-deterministic causal Conv1d training helpers and autograd entry points.
The module is a stable API; its backend package,
``flashinfer.experimental.cake.cake_causal_conv1d_nondet_train``, is
experimental and is imported on first use.
