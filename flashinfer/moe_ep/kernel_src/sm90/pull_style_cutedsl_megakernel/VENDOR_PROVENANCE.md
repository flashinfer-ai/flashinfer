## Included functionality

The unified drop contains:

- the existing Hopper FP8 fused MegaMoE path;
- Humming payload rewrite and folded-scale preprocessing;
- MXFP4 × FP8 FC1/FC2 and fused MegaMoE integration;
- hybrid-scale epilogue and packed logical/storage-K handling in the shared
  FP8 base;
- Green Context creation and graph lifecycle;
- `K0 → {K1 || K2} → K3` split execution, streaming handoff counters,
  reset/join and symmetric workspace protocol;
- explicit fused/split tactic and session/cache identity.

The local FlashInfer shim and public backend API are outside vendored `src/`.
Generated bytecode, benchmark blobs, donor tests, scripts and repository
scaffolding are intentionally excluded.

## Local extension status

`moe_hopper_fp8/heuristic_config.py` carries the FlashInfer
`token_back_mode` field per heuristic bucket. Preserve it when updating from a
drop that has not adopted it upstream.

Persistent fused/split MXFP4 autotune and cache selection are implemented
entirely outside vendored `src/`, in the local shim and backend.  Split keeps
its generation-bound fixed-pointer sessions and uses a dedicated tactic/cache
identity, so it cannot consume a fused MXFP4 or ordinary FP8 entry.  The vendor
package hashes recorded above remain unchanged by that integration.

## Update contract

1. Form the next update in a clean staging repository from the exact current
   package snapshot or a verified upstream baseline.
2. Copy `common/`, `src/`, `moe_nvfp4_swapab/` and `moe_hopper_fp8/`
   atomically. Do not cherry-pick individual dirty donor files.
3. Keep Green Context and split runtime in the unified drop; the historical
   instruction to exclude Green Context is superseded.
4. Keep all adaptation in `shim/`. Do not edit vendored `src/` after copying.
5. Remove `__pycache__`, `*.pyc` and `moe_hopper_fp8/benchmark_data`, then
   recompute package trees and aggregate hashes.
6. Rerun Humming/standalone, fused single/2/4-rank, split
