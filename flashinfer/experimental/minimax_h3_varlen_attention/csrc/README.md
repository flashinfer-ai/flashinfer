# Generated sources (placeholder)

`cake_minimax_h3_varlen_attention/<arch>/*.cu` is written by the Cake
generated-program export (`tools/export-generated-programs run` with
`exports/minimax_h3_varlen_attention/export.py` in the Cake repository).
It populates `../cake_jit.py` (`MODULES` and `ROUTES`) at the same time.
Nothing under this directory is hand-written; do not edit the generated
files.  Until the export has run, no program is registered and the public
entry points raise `NotImplementedError` naming the missing architecture.
