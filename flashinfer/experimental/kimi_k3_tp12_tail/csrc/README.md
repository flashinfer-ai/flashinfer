# Generated sources

The programs under `cake_kimi_k3_tp12_tail/` (one `*_kernel.cu` per program; one
`*_binding.cu` per launcher shape, where the two `k1_twoshot` programs share one
launcher selected by the `CAKE_PROGRAM_KERNEL` / `CAKE_PROGRAM_SHIM` /
`CAKE_BINDING_SMEM` compile definitions of each record; plus the shared device and
host headers and `cake_ffi_checks.h`) are generated by Cake.  Each program is one
source compiled for SM100a and SM103a; the lowering differences between the two
are `__CUDA_ARCH__` guards inside the source.  The generator rewrites
`../cake_jit.py` (`MODULES` and `KERNELS`) at the same time.  Nothing under this
directory is hand-written except the `#if` arms and guarded defaults of the file
marked "hand-edited here pending exporter support" (the shared `k1_twoshot`
launcher), which folds two formerly separate programs into one source; the other
generated files are reproduced by the generator.  Until the programs have been
generated, no program is registered and the public entry points raise
`NotImplementedError` naming the missing architecture.
